# Calcio History - Proyecto Académico

Aplicación web educativa sobre la historia y leyendas de clubes de fútbol europeo, desarrollada con HTML5, CSS3 y JavaScript nativo (LocalStorage).

## 🚀 Cómo ejecutar el proyecto localmente

1. Clona este repositorio o descárgalo como archivo ZIP.
2. Abre la carpeta del proyecto en **Visual Studio Code**.
3. Asegúrate de tener instalada la extensión **Live Server**.
4. Haz clic derecho sobre el archivo `index.html` y selecciona **"Open with Live Server"**.
5. ¡Listo! Navega libremente por las páginas de los clubes y la sección de contacto.
